# Employee Activity Monitoring System

Клиент-серверная система для мониторинга рабочей активности сотрудников на платформе .NET 10.

## Описание архитектуры

Проект состоит из двух ключевых компонентов:

1. **Клиентский агент (`src/Client.Agent`)**:
   - Разработан на C# (.NET 10).
   - Работает без использования сторонних сторонних NuGet-библиотек.
   - Автоматически запускается в фоновом режиме при входе пользователя в систему через HKEY_CURRENT_USER Run registry key.
   - Передает информацию о текущем домене, имени ПК, имени пользователя и IP-адресе.
   - Поддерживает снятие скриншота экрана пользователя и передачу на сервер по запросу.

2. **Серверная часть (`src/Server.Web`)**:
   - Разработана на ASP.NET Core Web API.
   - Предоставляет веб-интерфейс для мониторинга подключенных клиентов.
   - Отображает текущий статус клиентов (Online / Offline), IP-адреса и время последней активности.
   - Позволяет запрашивать и просматривать скриншоты рабочих столов клиентов.

## Сборка и запуск

### Требования
- .NET 10 SDK

### Инструкция по запуску

1. Запуск сервера:
   ```bash
   dotnet run --project src/Server.Web
   ```
   Сервер запустится по адресу: `http://localhost:5000`

2. Запуск клиентского агента:
   ```bash
   dotnet run --project src/Client.Agent
   ```

3. Для просмотра интерфейса откройте `http://localhost:5000` в браузере.
